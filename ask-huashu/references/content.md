# 内容与研究

从已有内容进入所需步骤，不必把每件作品都走成一条长流水线。

| 当前缺口 | 安装标识 | 带入 / 带出 |
|---|---|---|
| 没有值得展开的题目 | `huashu-topic-gen` | 受众、素材与目的 → 可比较的选题、标题和大纲 |
| 问题需要多轮查证 | `huashu-research` | 研究问题 → 随搜索轮次保存的来源、发现与缺口 |
| 要了解某产品或技术的当前情况 | `huashu-info-search` | 明确对象和时点 → 交叉核对的信息与知识记录 |
| 需要真实经历或案例 | `huashu-material-search` | 已授权的个人资料 → 可追溯的素材；先确认资料属于谁 |
| 修改现成文章 | `huashu-article-edit` | 原文与修改范围 → 可追踪的增量修改 |
| 文章结构、声音和经历都显得空泛 | `tramstop-skill` | 原文及作者真实材料 → 有证据支撑的去 AI 味改写 |
| 交付前做一遍文字打磨 | `huashu-proofreading` | 已定内容 → 内容、措辞和节奏三遍审校 |
| 长文转短社交文案 | `huashu-article-to-x` | 长文与目标渠道 → 短帖草稿 |
| 将现有内容搬到 X Articles / B 站等编辑器 | `dukou` | 已定内容 → 目标编辑器草稿；依赖浏览器扩展和本地桥 |
| X 内容策略或账号诊断 | `x-mentor-skill` | 真实账号数据与目标 → 内容策略；实际 name 是 `x-mastery-mentor` |
| 视频结构尚未确定 | `huashu-video-outline` | 主题、受众与时长 → 大纲和不同讲法 |
| 抖音竞品分析与脚本 | `huashu-douyin-script` | 获准使用的参考视频 → 分析、脚本和分镜；检查下载与模型接口依赖 |
| 口播像文章、说不顺 | `huashu-script-polish` | 脚本 → 可说出口的措辞、停顿和重音 |
| 标题、封面与开头接不上 | `huashu-video-check` | 视频及封标 → 可定位的承接问题和修改 |
| 演讲、讲解或排练需要反馈 | `huashu-speech-coach` | 讲稿、slides 或录制 → 针对听众体验的调整 |

个人素材检索中的作者资料不自动成为当前用户的经历。把用户原话、检索所得和创作补充区分开。资料查证完成后，需要正式报告时交给[数据与文档](data.md)，需要画面时交给[视觉制作](visual.md)。

草稿、上传和发布是不同动作。渠道流程只执行本次已经授权的范围。
