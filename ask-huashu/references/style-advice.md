# 风格顾问

用户问“这种情况该用哪种风格”，或有内容却不知道怎样表达时读。给出自己的判断，把专业选择翻译成用户看得懂的画面。

## 从场景推导，不从标签套用

把已有信息连成一个判断：**给谁看、在哪里看、要让他理解或感受到什么、手里有什么真实材料。** “科技”“高级”“国风”只提供线索，继续辨认作品要证明、解释、演示、打动还是吸引注意。

这沿用花叔原帖里反复出现的取舍：产品意义决定动效，参考片要拆运动与节奏的机制，创作工具应让人更容易表达和修改。原帖依据见[来源与取舍](sources.md)；具体样式与实现状态由下面的成员资料确认。

同一个技术产品可以需要严谨的系统图，也可以需要有冲击力的发布片。区别来自这次要完成的沟通，而不是产品被归到哪个行业。用户已有风格选择时，判断它怎样承载内容；只有发现实质冲突才提出调整。

## 到成员里找到具体选项

先定位成员目录，按需要读取以下相对路径。索引负责找候选，选中的卡片和可用样张负责校验实际建议。

## 形成提案

先给一个有理由的首选。方向仍开放时，再给有实质差异的备选：可以放大内容的某种力量，也可以换一种仍能表达主张的材料或叙事。用户已选定方向时，集中深化它。

每个建议应让用户知道：

- **用什么**：主技能、具体风格名或语言 ID，以及实际查阅的卡片/样张。库外方向标为新提案，并说明真实参考。
- **为什么**：场景中的哪个信号使这个选择成立；它帮助观众完成哪一步理解或感受。
- **会看到什么**：关键画面的构图、主角材料、字图关系；动画还说明一个核心动作和节奏。用当前内容举例。
- **怎样取舍**：与备选相比得到什么、牺牲什么；需要的素材、编辑能力和实现条件是否具备。
- **先验证什么**：一页、一帧或一个代表镜头应证明哪一点。咨询停在建议，制作请求继续产出这个验证片段。

保持自然表达，简单任务几句话就够。完成的标准是用户能据此作选择，随后制作的人不必重新猜测视觉意图。

## 用这些对照检验判断

下面是依据成员资料推导的示例，不是花叔对这些具体任务的本人意见，也不是固定默认。

| 场景差异 | 可以从哪里起步 | 判断要落在哪里 |
|---|---|---|
| 同一组研究数据：让专家核查 / 做现场结论演讲 | Design 信息图区的 `Open Research Data` 或 `Small Multiples` / PPT 区的 `Neo-Swiss Billboard Editorial` | 前者让口径、比较和来源易读；后者把最重要的判断拉到观看距离上。比较图仍需保留必要尺度和证据。 |
| 同一款软件：展示怎样操作 / 解释内部怎样工作 | Motion 的 `cursor-demo` / `mechanism` 或 `system-diagram` | 前者让观众跟随真实操作看到结果；后者让状态变化或部件关系可见，单纯播放 UI 不足以解释机制。 |
| 同一段科普：逐步推理 / 核对原始材料 | Art Motion 的白板或 `t1_3b1b` / `y2_vox` | 推理让关系逐步出现；材料论证让观众看见原文、图像和被标注的证据。是否有数学对象决定 3b1b 是否合适。 |
| 同一个“水墨”要求：保留教学精度 / 主打艺术情绪 | Art Motion 的已验证解说语法配合受控水墨语言 / 对应水墨风格配方的场景试作 | 先决定字、关系和数据如何读清，再决定笔墨占比；配方索引的质量与迁移限制必须进入建议。 |

如果不同受众、材料和目的最后都得到同一套“极简、留白、渐变”，回到场景重新作判断。风格库是表达词汇；这次作品的理由要来自这次内容。
