# 来源与取舍

这个入口把公开创作实践整理成工作方法与路由，不代表花叔本人逐条审定。结构借鉴 Ask Matt 的主线、入口和分支写法；内容按花叔自己的作品与源码重新组织。

## 怎样处理差异

- 一次 MV 演示明确要求跳过审片，不能据此把跳过检查推广成通用方法。
- 颜色限制、镜头配额和模型分档属于具体流程；共同的判断是内容驱动和实际观看，不是固定外观。
- Design 与独立 Motion 的分工在演进，任务目标与现有工程比名称更能决定路线。
- 人物视角是对公开材料的提炼，不是本人意见；实际数据、产品事实和当前用户选择保持各自来源。

## 更新时核对

先看 [skills.json](https://github.com/alchaincyf/huashu-skills/blob/master/skills.json) 和实际 `SKILL.md`。目录数量、宣传文案或 X 搜索摘要可能滞后。保留仍然有证据的判断；有冲突就改对应分支，不累积成越来越多的通用禁令。
