# 数据与文档

| 当前任务 | 安装标识 | 选择依据 |
|---|---|---|
| 脏表清洗、指标口径、计算与对账 | `huashu-excel` | 数字是否可信是主要问题 |
| Excel 到交互 HTML / PDF 分析成品 | `huashu-data-pro` | 主要目标是分析报告或交互呈现，仍需核实数据口径 |
| 研究报告、白皮书、调研或学术论文 | `huashu-report` | 论证、证据和报告结构是主要工作 |
| 多种文件转 Markdown，或 Markdown 出 HTML / DOCX 等 | `huashu-md-html` | 输入输出转换与出版排版 |
| 已定 Markdown 直接排成 PDF | `huashu-md-to-pdf` | 单一 PDF 交付即可 |

顺序取决于缺口。数值尚未对上，先对账；证据齐全而结构不成立，先处理论证；内容已定，再做排版。图表的数字与正文同源，修订时一起更新。

正式报告中的演示稿仍由研究内容决定结构。普通演讲 deck 则进入[视觉制作](visual.md)。交接保留原始来源、计算口径、图表数据及尚未解决的问题。
